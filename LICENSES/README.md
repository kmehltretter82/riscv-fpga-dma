# Licenses

Source files retain their original SPDX identifiers and copyright notices.
This directory carries the common license texts used by the snapshot. Some
hardware sources use the Solderpad Hardware License or an Apache/Solderpad
expression; their file headers remain authoritative and link the applicable
version when it differs from SHL-0.51.

Upstream repositories restored by `bootstrap-sources.sh` retain their own
complete license files.
